### Hi, I'm Matt 👋

I'm a senior product designer who builds. For 12+ years I've designed complex enterprise products: global rewards at American Express, security and identity at Cisco, and now real-time operations for public safety at [Axon](https://www.axon.com). Lately more of my design work happens in code: I prototype in the browser, ship small tools and write about how AI is changing the way designers make things.

**Design doesn't end in Figma.**

#### What I'm building

- **[Localhost Bar](https://github.com/matt-pointon/localhost-bar)**: a macOS menu bar app that finds the dev servers running on your machine and shows each one's git status, stack, the AI coding tool behind it, and one-click actions (open, copy URL, commit, PR). It started in Electron + React + Tailwind and has a native Swift/SwiftUI version with a widget and Siri Shortcuts.
- **[BananaStack™](https://github.com/matt-pointon/gemini-bananaSaaS)**: a satirical enterprise-SaaS landing page I made to test Gemini 3. It uses glitch type, glassmorphism and Framer Motion. I wrote it up in [From Bananas to Breakthroughs](https://notanothertab.substack.com/p/from-bananas-to-breakthroughs-what).
